## 2. User → assistant (6 Nov 2026, in chat)
> "my phone's device care says that the reelmonster keeps crashing, and also it really is getting crashed and not working... now what to do"

Result: read `MonsterService.kt` and the manifest; diagnosed the crash as a missing foreground-service type (two-argument `startForeground()` with no `foregroundServiceType` declared; Android 14+ rejects this for targetSdk 34). Fixed in the local copy and gave the user the same 3 edits for his PC copy: manifest declares `foregroundServiceType="specialUse"` + `FOREGROUND_SERVICE_SPECIAL_USE` permission + special-use subtype property; `MonsterService` uses `ServiceCompat.startForeground(..., FOREGROUND_SERVICE_TYPE_SPECIAL_USE)`. User applied the fix, re-ran, and reported Level 1 manual counting working (12–13 reels, count stored).
